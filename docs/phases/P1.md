# P1 — オブジェクトメモリ

## 結論

64-bit tagged `ao::Oop`、ヒープ割り当て、正確 GC（nursery bump + old mark-compact）を出す。

## 前提

P0 緑。SPEC §3.1, §3.2。

## 範囲

**やる:** タグ往復、オブジェクトヘッダ、nursery、old 世代、ルート API。

**やらない:** メソッド辞書、lookup、クラス意味論（スロットはあるが送信しない）。

## 仕様

タグ（SPEC §3.1）:

- bit 0 = 1 → SmallInteger（符号付き 63-bit、算術右シフト 1）
- bit 1:0 = 10 → Character
- bit 2:0 = 100 → 即値 nil / true / false
- bit 2:0 = 000 → ヒープ（8 バイト整列）

ヘッダ: class OOP 64、size 32、flags 16、hash 16。公開 OOP は `ao::Oop`。生 `uint64_t` を散らさない。

GC: 正確式。ファイナライザと弱配列は弱スロットフラグまで（ephemeron なし）。ミューテータ 1 本。mimalloc はまだ入れない。
