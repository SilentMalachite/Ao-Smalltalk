# P17 — Smalltalk のチェンジセット

## 結論

P16 のチェンジセットを、C++ のセッションメモリ（`Session::changes`）から Smalltalk のクラス `ChangeSet`（`image/Tools-model/ChangeSet.st`）に移し、イメージに保存されるようにする。ABI（`ao_changes_*` の 12 関数）と Change Sorter の操作は P16 のまま。Kernel は C++ のネイティブのままで、足すのは `Behavior>>sourceCodeAt:` と `Class>>definition` の 2 つだけ。C++ は、Accept・削除・File In… の成功のあとに `ChangeSet` へ記録のメッセージを送る薄い層になる。正本は SPEC §3.7、§3.9「Change Sorter（P16）」「起動と同梱」、§3.10「チェンジセット（P16）」、§3.11、§3.12、§6「Smalltalk のチェンジセット（P17）」。実装計画は [`superpowers/plans/2026-10-12-p17-smalltalk-change-sets.md`](../superpowers/plans/2026-10-12-p17-smalltalk-change-sets.md)、設計は [`superpowers/specs/2026-10-12-p17-smalltalk-change-sets-design.md`](../superpowers/specs/2026-10-12-p17-smalltalk-change-sets-design.md)。版は 1.6.0 だが、1.6.0 はリリースせず、P16・P18 とまとめて 1.7.0 で出す（SPEC §2.4）。

## 前提

P16 緑（PR #28 マージ済み）。SPEC の P17 追記は実装より先。

## 範囲

**やる:** `image/Tools-model/` の `ChangeSet` と `ClassChanges`（Smalltalk、Kernel のネイティブだけを使う）、遅延の初期化、イメージへの保存（セット・current・ID が戻る）、Tools-model の file-in（アプリの起動と、`ChangeSet` の無いイメージを Open Image… したとき。`ao --test` はテストの隣の Tools-model）、`ao filein` と `ao image save` の `--load-order` の繰り返し、`Behavior>>sourceCodeAt:` と `Class>>definition`、File Out の本文を Smalltalk で書く（`fileOutStringDate:version:`）、C++ の最外の送信の手当て（ライブデバッガを止めない、スナップショットを置き換えない）、`ao_changes_*` の読み出しは busy なら拒む、Change Sorter の busy の表示とイメージを開いたあとの表示、`scripts/package-app.sh` の同梱。

**やらない:** Kernel の Smalltalk 化、Accept の Smalltalk 化、FileStream などのファイル I/O のクラス、Smalltalk からのファイル書き込み、Browser など、ほかのツールのモデルの移行、セットの改名と削除、メソッドのスタンプと作者、Workspace の評価の記録、イメージの版（3）の変更。
