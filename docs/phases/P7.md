# P7 — イメージ

## 結論

`.aoimage` の save / load。起動時に再配置し、NativeMethod はシンボル名で結び直す。

## 前提

P6b 緑。SPEC §3.11。

## 範囲

**やる:** マジック `AOIM`、バージョン、ポインタサイズ、エンディアン、well-known、ヒープダンプ、グローバル辞書、再結合。

**やらない:** 関数ポインタのファイル書き込み、他処理系 .image 互換。

## 仕様

直接ポインタはファイル内オフセットに再配置。`NativeMethod` は安定シンボル名（`ao_Object_identityEquals` 等）。
