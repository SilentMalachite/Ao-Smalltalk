# P6 — インタプリタ

## 結論

ユーザーメソッドを実行する。コンテキストとブロックが動く。`ao --test` で `image/tests/*.st` を走らせる。

## 前提

P5 緑。SPEC §3.4, §3.5。

## 範囲

**やる:** MethodContext / BlockContext（または統一 Context + フラグ）、バイトコードループ、ブロック、テストランナー。

**やらない:** JIT 本体、ホストプリエンプション、vendor file-in。

評価 ABI を足すなら **SPEC §3.10 を先に更新** してから `bridge/ao_abi.h` を増やす。

## 仕様

協調的プロセス。長時間ネイティブは自ら safepoint。ブロックは外側コンテキストとコピーされた値。フルクロージャ（共有 temps）へ拡張できる構造にする。

## TDD

`compiler_roundtrip_test`、`block_test`、ゴールデン `image/tests/*.st`。

## 制約

Kernel ホットパスにインタプリタを介入させない（SPEC §1.3）。ユーザーメソッドだけがインタプリタに入る。

## 受け入れ

- [x] ソース → バイトコード → 評価が一致する
- [x] ブロック引数・返り値・外側 temps
- [x] `ao --test` が image/tests を実行する
