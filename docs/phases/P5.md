# P5 — コンパイラ

## 結論

Smalltalk-80 メソッドソースとチャンク形式を AST 経由で `CompiledMethod`（バイトコード）にする。実行しない。

## 前提

P4 緑。SPEC §3.5, §3.8。

## 範囲

**やる:** 字句、構文、ISA ヘッダ、コード生成、チャンク file-in パーサ。

**やらない:** インタプリタループ（P6）、vendor 一式のロード（P6b）。

## 仕様

必須構文: カスケード `;`、キーワード / バイナリ / ユニタリ、ブロック、一時変数、リテラル、擬変数、`:=` と入力 `_`（保存は `:=`）。

エラーはソース区間付き。JIT スロット `nativeCode` は予約し常に nil。

## TDD

パース成功 / 失敗区間、カスケード・キーワード・ブロック AST、生成バイトコードのスナップショット（安定したら固定）。

## 制約

Kernel をバイトコードで実装しない。既存処理系のコンパイラをコピーしない。

## 受け入れ

- [ ] 正しいメソッドソースが CompiledMethod になる
- [ ] 不正ソースが区間付きで失敗し、既存テキストを壊す副作用が無い（モデル上）
