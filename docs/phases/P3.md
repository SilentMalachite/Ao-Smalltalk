# P3 — ネイティブディスパッチ

## 結論

メッセージ送信、`NativeMethod`、メソッドキャッシュを出す。Kernel プロトコルの充足は P4。

## 前提

P2 緑。SPEC §3.3。セレクタマングルは `docs/native-selectors.md` に一度だけ書く（CLAUDE.md）。

## 範囲

**やる:** Symbol intern、MethodDictionary、NativeMethod、lookup / super / DNU、IC 1 段 + クラスキャッシュ。

**やらない:** CompiledMethod 実行、Kernel 全セレクタ。

`native_send_test` の `1 + 2` は経路証明用の最小 `SmallInteger>>+` でよい。P4-03 で SPEC の算術（オーバーフロー → LargeInteger）に置き換える。

## 仕様

lookup 通常パス: IC → class method cache → 辞書（Symbol identity）→ `doesNotUnderstand:`。

メソッドは 2 種類だけ: NativeMethod / CompiledMethod。P3 では NativeMethod のみ適用する。

マングル: `ao_<Class>_<selectorMangled>`。`==` → `identityEquals`、`+` → `add`。
