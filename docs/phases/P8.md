# P8 — AppKit ツール

## 結論

独立 NSWindow の Transcript / Workspace / System Browser。見た目は macOS 標準。

## 前提

P7 緑。SPEC §3.9, §3.10。バンドル ID `jp.ao.smalltalk`（変更するなら SPEC 先）。

## 範囲

**やる:** Ao.app 骨格、3 ツール、メニュー、キーバインド。

**やらない:** SwiftUI 主系統、クラシック白黒画面、デバッガ、チェンジセット UI。

## 仕様

5 ペイン Browser。Do it は `⌘D`。Print it は `⌘I`（`⌘P` は使わない）。評価の `self` は `nil`。ワークスペース変数は v1 で実装（P9 と分担してよい。P8 は窓とメニューまで）。

ランタイム呼び出しは `bridge/ao_abi.h` のみ。AppKit オブジェクトを OOP ヒープに置かない。ホストハンドル表。

## TDD

XCTest: ABI 経由の評価（エントリが SPEC 更新済みなら）、Browser モデルの列挙。ウィンドウ操作の自動は必須としない。モデルテストを優先。

## 制約

`@MainActor` を GUI に付ける。強制アンラップを新規に増やさない。

## 受け入れ

- [x] 起動すると Transcript と Workspace が出る（実装後の手動確認を文書化）
- [x] Tools から Browser を開ける
- [x] メニューバー: Ao / File / Edit / Smalltalk / Tools / Window / Help

## 手動確認

1. リポジトリ直下で `./scripts/package-app.sh` のあと `./build/Ao.app/Contents/MacOS/Ao` を起動する（`open` はカレントディレクトリを変える）。
2. Transcript と Workspace が 1 枚ずつ出る。
3. Tools の Browser で System Browser が開き、同じ項目をもう一度選ぶと前面に戻る。Transcript と Workspace も同様。
4. File の Close（⌘W）、最小化、Spaces は標準の NSWindow に任せる。自動テストは `NSApplication.run()` を呼ばない。
5. Help はバージョン `0.0.0-p8` を NSAlert に出す。Do it / Print it / Inspect it / Accept は何もしない。
