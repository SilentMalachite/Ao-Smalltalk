# P11 — ライブデバッガ

## 結論

`halt` と失敗で評価を **止め**、Debugger 窓から Proceed / Abort / Step する。評価をベースでなく専用の fork プロセス（評価プロセス）で走らせ、止まったプロセスのフレームを P10 の連鎖（`CallContext::topFrame`）から直接読む。正本は SPEC §3.13 の「ライブデバッガ」、§3.10 の「ライブデバッガの操作」、§3.9 の「ライブ Debugger」である。計画書は [`docs/plans/p11-ancient-matsumoto.md`](../plans/p11-ancient-matsumoto.md)。

## 前提

P10 緑（`b89dde7`）。P11-01 で SPEC §3.13 に詳細を書き足す。P10 の `ao_debug_frame_*` の読みを、スナップショットと止まったプロセスを同じ形で読める抽象（`DebugFrames`）の上に移す（P11-03）。

## 範囲

**やる:** 評価プロセス、止める（`halt` / `error:` / DNU / `failed: #sel` / `NonBoolean receiver` / `cannot return`）、`AO_ERR_HALT`、Proceed / Abort / Step into / over / out、Debug it、Debugger 窓の操作ボタン、止まったプロセスのある `ao_image_save` の拒否。

**やらない:** Restart（フレームの再実行）、デバッガ内の編集と Accept、temp の書き換え、ネイティブへの step into、ベースの停止、CLI / `ao --test` の変更。

## 仕様（設計判断）

- **評価プロセス**: ホストが `ao_set_debug_mode(AO_DEBUG_LIVE)` を有効にしたとき、`ao_eval` の doIt をベースでなく fork したプロセスで走らせる。ベースは `terminate` の「相手の終わりを待つ」機構（`resumeTo`）と同じ形で待ち、評価プロセスが切り替えたら drain と同じ規則で回し、終わるか止まるかで `ao_eval` から戻る。ライブモードでない評価（CLI、`ao --test`、既定）は変えない。ワークスペースの束縛は共有のまま。
- **止める**: 評価プロセスでは `halt` / `error:` / DNU / `failed: #sel` / `NonBoolean receiver` / `cannot return` は、巻き戻す前にそのプロセスを止める（`suspend` と同じ状態 + 理由）。`ao_eval` は `AO_ERR_HALT`（6）と理由を返す。stack overflow、out of memory、deadlock、プロセス操作の失敗は止めず、今までどおり abort（P10 の捕捉が残る）。
- **フレームの供給元**: 止まったプロセスのフレームは `ctx.topFrame` の生きた連鎖から読む。ファイバのスタックは止まっている間は有効。
- **操作**: `ao_debug_proceed(pid)` = resume して、止めた送信の値として nil を返す（Blue Book）。`ao_debug_abort(pid)` = terminate（後始末を走らせる）。`ao_debug_step_into / over / out(pid)` = プロセスごとの `stepMode` を立てて resume。インタプリタループの先頭で 1 分岐。step over は同じフレームの次の文の先頭（pc→ソース表の文の項目）、step into は次の解釈フレームの先頭、step out はフレームが sender に戻ったところで止まる。どれも `ao_eval` の末尾と同じく、終わるか止まるまで回して結果（`out` / `AO_ERR_HALT` / `AO_ERR_EVAL`）を返す。
- **Debug it**: Smalltalk メニューに `Debug it`（⌘⇧D）。最初のバイトコードで止める。
- **busy とイメージ**: 止まったプロセスは走っていないので busy でない。デバッガを開いたまま別の Do it ができる。同時に止まれる評価プロセスは 8 まで。止まったプロセスはファイバの C++ スタックを持つのでイメージに書けない。`ao_image_save` は止まったプロセスがあれば `AO_ERR`（理由 `halted processes`）で拒む。
- **窓**: P10 の Debugger 窓に Proceed / Abort / Step over / Step into / Step out のボタンを足す。止まったプロセスの窓は generation でなく pid で識別する。
