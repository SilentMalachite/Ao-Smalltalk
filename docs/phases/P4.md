# P4 — Kernel ネイティブ実装

## 結論

SPEC §3.6 のクラス群をすべて NativeMethod で充足する。インタプリタで Kernel を書かない。

## 前提

P3 緑。対応 `.st` はコメントとプロトコルのみ。

## 範囲

**やる:** Kernel-Objects / Classes / Methods / Processes、Collections 中核、Magnitude、Graphics-min（Point, Rectangle）、Streams / Transcript モデル / SmalltalkImage。

**スタブ可:** Bag, LinkedList, MappedCollection, Date / Time。

**やらない:** バイトコードインタプリタ、BitBlt / Form、Browser ビュー。

## 仕様

必須セレクタは SPEC §3.6 の箇条書き。増やすなら Blue Book プロトコルに従い SPEC を先に更新してもよいが、便利ユーティリティの量産は禁止。

`SmallInteger` 算術のオーバーフローは LargeInteger へ透過。

## TDD

`smallinteger_arith_test`、`collection_do_test`、`transcript_model_test`、Kernel 走査（メソッド辞書の値はすべて NativeMethod）。`docs/bench.md` に `1 to: 10000000 do: [:i | i + 1]` 相当を記録（SPEC §6 性能）。

## 制約

CI で Kernel 走査が赤の変更はマージしない（SPEC §6）。走査テストは P4-09 で入れる。
