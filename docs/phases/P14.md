# P14 — ライブ Debugger の Restart

## 結論

ライブ Debugger で選んだ解釈フレームを本体の先頭からやり直す。正本は SPEC §3.9「ライブ Debugger」、§3.10「ライブデバッガの操作」、§3.13「操作」、§6「Restart」。設計の理由は [`superpowers/specs/2026-10-03-debugger-restart-design.md`](../superpowers/specs/2026-10-03-debugger-restart-design.md)。次のマイナー版（1.3.0）に含める（SPEC §2.4）。

## 前提

P13 緑（1.2.0 リリース済み）。SPEC の P14 追記は実装より先。

## 範囲

**やる:** `ao_debug_restart` / `ao_debug_can_restart`、対象解釈フレームへの巻き戻しと活性化の初期化（内側の `ensure:` は走らせない）、Debugger の Restart ボタン、関連の GoogleTest / XCTest。

**やらない:** チェンジセット、Debugger 内編集と Accept、temp 書き換え、ネイティブフレームの Restart、事後 Debugger からの Restart、CLI の変更。

## TDD

`debug_abi_test` の `LiveRestart.*` と `DebuggerWindowTests` の Restart。
