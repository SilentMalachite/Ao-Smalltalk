# P10-04: セッションのソース表の拡張と doIt

- 親フェーズ: [P10](../phases/P10.md)
- 状態: done
- 依存: P10-02、P10-03

## 目的

pc→ソース表と temp 名をメソッド（本体と入れ子ブロック）とセッションのソース表で結び、doIt のソースも直前の 1 件だけ持ち、スナップショットをセッションに配線する。SPEC §3.10「ソースはイメージに書かない」の拡張。

## Files

- Modify: `runtime/src/Session.hpp`（`MethodSource` にブロックのルート付きスロット、`std::shared_ptr<const DebugInfo>`、`sourceOffset`。`Session::doItDebug`。`Session::debug` は `roots` より **あと** に宣言）
- Modify: `runtime/src/Session.cpp`（`rememberMethodSource(kept, text, replaced, const compiler::MethodImage*)` がブロックをリテラル添字で対応付ける。`moveMethodSource` がブロックを付け直す。`methodSourceRootSlots` がブロックとスナップショットのスロットも返す。`evalBody` が箱詰め後に `doItDebug` を入れる。`sessionEval` の入口でスナップショットと `doItDebug` を消す。`installEmptyCache` が `ctx->debug` を配線し、`setSessionDebugCapture` で外す）
- Modify: `runtime/src/Compile.cpp`（`acceptMethodSource` 1409 行付近で `&cr.image` を渡す。`liveClasses` は `methodSourceRootSlots` 経由のまま）
- Modify: `runtime/tests/accept_abi_test.cpp`、`runtime/tests/session_abi_test.cpp`

## Interfaces

- Consumes: `MethodImage::pcMap` / `temps`（P10-02）、`DebugSnapshot`（P10-03）、`boxMethodImage` のブロックのリテラル添字（Compile.cpp 1187–1193 行）
- Produces: `Session::methodSource(oop)` が本体でもブロックでも同じ項目を答える。`Session::debugInfoFor(method)`。`HideMethodSources`（イメージ保存）と `liveClasses`（形の変更）がブロックとスナップショットを隠す

## テスト

赤にしてから実装:

- `AcceptAbi.AcceptKeepsPcMapForMethodAndBlocks`
- `AcceptAbi.ReacceptDropsOldMethodAndItsBlocks`
- `AcceptAbi.ReshapeKeepsBlockPcMaps`（形の変更で `moveMethodSource` がブロックを付け直す）
- `SessionAbi.ImageSaveDoesNotTraceSnapshotOrBlockSlots`
- `SessionAbi.DoItDebugInfoDropsPrefix`（`kDoItPrefix` を引いた座標）
- `SessionAbi.NextEvalClearsSnapshot`

## 手順

この PR を実装するセッションは `graphify-out/GRAPH_REPORT.md` を読み、`graphify path Session Roots` で経路を取り、Serena で `Session::rememberMethodSource`、`moveMethodSource`、`methodSource`、`methodSourceRootSlots`、`HideMethodSources`、`liveClasses`、`acceptMethodSource`、`evalBody`、`sessionEval`、`installEmptyCache` の定義と参照を取ってからテストを赤にする。`replace_symbol_body` で直す。

P1 以降のコードをこの PR 文書の範囲外で書かない。ABI は P10-05。
