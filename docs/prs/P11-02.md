# P11-02: 評価プロセス

- 親フェーズ: [P11](../phases/P11.md)
- 状態: done
- 依存: P11-01

## 目的

ライブモードの `ao_eval` の doIt を評価プロセスで走らせる（SPEC §3.13「評価プロセス」）。ここではまだ止めない。失敗は今までどおり abort で、`AO_ERR_EVAL` と理由を返す。

## Files

- Modify: `runtime/include/ao/Scheduler.hpp`、`runtime/src/Scheduler.cpp`（`forkEval`、`awaitEval`、`Record::isEval`、評価の結果の枠（ルート）、`runFiber` の分岐、評価プロセスのデッドロック、pid を使い回さない番号）
- Modify: `runtime/src/Session.hpp`、`runtime/src/Session.cpp`（`setSessionDebugMode`、`evalBody` のライブの経路、`Session::onAbort` で評価プロセスをベースと同じに扱う）
- Modify: `runtime/src/abi.cpp`、`bridge/ao_abi.h`（`ao_set_debug_mode`）
- Modify: `runtime/tests/session_abi_test.cpp`、`runtime/tests/process_test.cpp`

## Interfaces

- Consumes: `Scheduler::terminate` の待ち方（`resumeTo`、`awaitingTerminate`）、`takeNext`、`afterResume` の `deadlockPending`、`printStringOf`、`inspectValue`
- Produces: `Scheduler::forkEval(ctx, method, mode)`（pid）、`Scheduler::awaitEval(pid)`（終わった / 失敗した / 止まった）、`ao_set_debug_mode`。CLI、`ao --test`、既定は変えない

## テスト

- `SessionAbi.LiveModeRunsDoItOnEvalProcess`（`Processor activeProcess` がベースと違う。Print it の値が出る）
- `SessionAbi.LiveModeErrorAnswersEvalErrorAndCaptures`（`AO_ERR_EVAL` と理由、スナップショットがあり、プロセスの失敗に数えない）
- `SessionAbi.LiveModeDeadlockFailsEvalProcessAndRunsEnsure`
- `SessionAbi.LiveModeSharesWorkspaceBindings`
- `SessionAbi.LiveModeForkAndYieldMatchesBase`（`[n := n + 1] fork. Processor yield. n` が `1`）
- `SessionAbi.LiveModeSelfTerminateAnswersProcessTerminated`
- `SessionAbi.DefaultModeUnchanged`、`SessionAbi.DebugModeSurvivesBootAndLoad`

## 手順

`graphify explain resumeTo` と `graphify path Scheduler Session --undirected` で経路を取り、Serena で `Scheduler::terminate`、`runFiber`、`takeNext`、`afterResume`、`finishFiber`、`evalBody`、`sessionEval`、`Session::onAbort` の定義と参照を取ってからテストを赤にする。
