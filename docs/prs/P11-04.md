# P11-04: Proceed / Abort

- 親フェーズ: [P11](../phases/P11.md)
- 状態: planned
- 依存: P11-03

## 目的

止まったプロセスを続ける（Proceed）か終わらせる（Abort）。SPEC §3.13「操作」、§3.10「ライブデバッガの操作」。

## Files

- Modify: `runtime/include/ao/Scheduler.hpp`、`runtime/src/Scheduler.cpp`（`resumeHalted`、止まったプロセスへの `terminate`）
- Modify: `runtime/src/Session.hpp`、`runtime/src/Session.cpp`（`ao_eval` の末尾を共有して Proceed と Abort に使う。止めた評価の mode）
- Modify: `runtime/src/abi.cpp`、`bridge/ao_abi.h`（`ao_debug_proceed`、`ao_debug_abort`）
- Modify: `runtime/tests/debug_abi_test.cpp`

## Interfaces

- Consumes: P11-03 の `stopOrAbort`、`State::Halted`、`awaitEval`
- Produces: `ao_debug_proceed(pid, out, out_len, err)`、`ao_debug_abort(pid)`。答えは `ao_eval` の末尾と同じ

## テスト

`debug_abi_test`: `ProceedAnswersNilAndFinishesPrintIt`、`ProceedCanHaltAgain`、`ProceedFailedSendPushesNil`、`AbortRunsEnsureBlocks`、`ErrorInCleanupDuringAbortDoesNotStop`、`ProceedOnNonProceedableIsRefused`、`AbortNonProceedableRunsEnsure`、`ProceedWhileBusyIsRefused`、`ProceedUnknownPidFails`、`TerminateFromSmalltalkEndsHaltedProcess`。
