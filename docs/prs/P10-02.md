# P10-02: コンパイラの pc→ソース表と temp 名

- 親フェーズ: [P10](../phases/P10.md)
- 状態: planned
- 依存: P10-01

## 目的

デバッガがフレームの pc からソースの区間を引き、temp を名前で見せられるように、コンパイラが `MethodImage` に pc→ソース表と temp 名を出す。SPEC §3.8（P10-01 で改訂）。イメージには書かない。CompiledMethod の形は変えない。

## Files

- Modify: `compiler/include/ao/MethodImage.hpp`（`PcSpan {pc, start, end}`、`TempName {name, kind, slot | (vectorTemp, vecIndex) | (copiedIndex, vecIndex)}`、`MethodImage::pcMap`、`MethodImage::temps`）
- Modify: `compiler/src/Codegen.cpp`（`Emitter::mark(SourceSpan)`、`compileSend`、`compileCascade`、`compileReturn`、`compileInlined`、`compileToDo`、`compileStmt`、`compileMethod`、`compileBlockMethod`）
- Create: `compiler/tests/pc_map_test.cpp`
- Modify: `compiler/CMakeLists.txt`（9–11 行の `add_executable` に足す）

## Interfaces

- Consumes: `Ast` の `SourceSpan`、`Emitter` の `real_->vars` / `real_->copied`、`vectorTemp`
- Produces: `MethodImage::pcMap`（pc について整列済み。Send / SendSuper / SendSpecial / Jump* / Return* / ReturnBlock の直前と各文の先頭）と `MethodImage::temps`。ブロックは自分の `MethodImage` に自分の表（座標は外側メソッドのソース）。`compileInlined` の `JumpTrue` / `JumpFalse` は **レシーバ** の span。`disassemble` と `Literal` の深いコピーは変えない

## テスト

`pc_map_test.cpp`（赤にしてから実装）:

- `PcMap.SendPcMapsToSendSpan`: `foo ^self bar: 1` の Send の pc が `self bar: 1` の区間
- `PcMap.InlinedConditionJumpMapsToReceiverSpan`: `x ifTrue: [1]` の JumpFalse が `x` の区間
- `PcMap.ReturnBlockMapsToReturnStatement`: `[^1]` の ReturnBlock が `^1` の区間
- `PcMap.BlockMethodHasItsOwnMapInMethodCoordinates`: ブロックの `MethodImage` の表が外側のソースの座標
- `PcMap.TempNamesListArgsTempsAndLoopVars`: 引数、temp、`to:do:` のループ変数が宣言順
- `PcMap.RemoteTempNamesVectorSlotAndIndex`: 代入される捕捉 temp が (vectorTemp, vecIndex)
- `PcMap.CopiedOuterTempIsNamedInBlockScope`: ブロックの表にコピーした外側変数が copiedIndex で載る
- `Codegen.*`（`codegen_snapshot_test.cpp`）がバイト一致のまま

## 手順

この PR を実装するセッションは `graphify-out/GRAPH_REPORT.md` を読み、`graphify query "Codegen Emitter MethodImage SourceSpan"` で経路を取り、Serena で `Emitter::compileSend` / `compileReturn` / `compileInlined` / `compileToDo` / `compileStmt` / `compileCascade` / `compileBlock` / `compileMethod` / `compileBlockMethod` / `vectorTemp` の定義と、`MethodImage` の全参照（`Literal` の深いコピー、`boxMethodImage`）を取ってからテストを赤にする。`insert_after_symbol` で `mark` を足し、`replace_symbol_body` で各 compile* を直す。新規ファイル作成後は overview を取る。

P1 以降のコードをこの PR 文書の範囲外で書かない。ランタイム（`Session`、`Compile.cpp`）は触らない（P10-04）。
