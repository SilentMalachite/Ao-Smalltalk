# P11-03: 止める、止まったプロセスのフレーム、保存の拒否

- 親フェーズ: [P11](../phases/P11.md)
- 状態: done
- 依存: P11-02

## 目的

評価プロセスを止める（SPEC §3.13「止める」）。止まったプロセスのフレームを連鎖から読む（「止まったプロセスのフレーム」）。止まったプロセスがあれば保存を拒む（§3.11）。Proceed と Abort は P11-04。

## Files

- Modify: `runtime/include/ao/Send.hpp`、`runtime/src/Send.cpp`（`stopOrAbort`、`stopFailedSend`。`truthOf` の本体）
- Modify: `runtime/src/kernel/Object.cpp`（`halt`、`error:`、`doesNotUnderstand:`、`mustBeBoolean`）、`runtime/src/kernel/BlockContext.cpp`（`cannotReturn:` は `error:` を通さない）
- Modify: `runtime/src/Interpreter.cpp`（`performSend` の失敗した送信）
- Modify: `runtime/include/ao/Scheduler.hpp`、`runtime/src/Scheduler.cpp`（`State::Halted`、`canHalt`、`halt`、上限 8、`suspend` / `resume` / `terminate` の扱い、止まったプロセスの数と最後の pid、フレームの供給）
- Modify: `runtime/include/ao/DebugSnapshot.hpp`、`runtime/src/DebugSnapshot.cpp`（`DebugFrames` に `total`、`reason`、`context`、`sendArgCount`、`sendArg`。`LiveFrames`。合成を共有の関数に）
- Modify: `runtime/src/Session.hpp`、`runtime/src/Session.cpp`（読みを `const DebugFrames&` 経由に、`ao_debug_select`、止まった doIt の項目を残す）

- Modify: `runtime/src/abi.cpp`、`bridge/ao_abi.h`（`ao_debug_halted_pid`、`ao_debug_halted_count`、`ao_debug_can_proceed`、`ao_debug_select`）
- Modify: `runtime/tests/debug_abi_test.cpp`、`runtime/tests/image_save_load_test.cpp`

## Interfaces

- Consumes: P11-02 の評価プロセス、P10 の `DebugSnapshot::capture` の合成、`frameLabel`、`debugSpanAt`
