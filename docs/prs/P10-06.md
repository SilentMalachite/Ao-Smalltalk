# P10-06: Debugger 窓と Workspace の Debug ボタン

- 親フェーズ: [P10](../phases/P10.md)
- 状態: planned
- 依存: P10-05

## 目的

Ao.app の Debugger 窓（frames / source / variables）と、Workspace のエラー帯の Debug ボタン、`process failed:` の表示。SPEC §3.9「Debugger」（P10-01 で改訂）。ランタイム呼び出しは `bridge/ao_abi.h` のみ。

## Files

- Create: `app/Ao/DebuggerWindow.swift`
- Create: `app/AoTests/DebuggerWindowTests.swift`
- Modify: `app/Ao/WorkspaceWindow.swift`（`installErrorField` の帯に `NSButton`。`run` のあとに `ao_debug_frame_count()` を見てボタンと `process failed:` を出す。`openDebugger`）
- Modify: `app/Ao/LaunchSet.swift`（boot の直後に `ao_set_debug_capture(1)`）
- Modify: `app/Ao/AoApp.swift`（`resizeText` に開いている Debugger の `applyFont()`）

## Interfaces

- Consumes: `ao_debug_*`（P10-05）、`makeToolTextWindow`、`ToolTextSize`、`utf16Range(of:in:)`、`InspectorWindow` と `onClose`、`aoWorkspaceInspectHook` と同じトランポリン
- Produces: `DebuggerWindow`（`@MainActor final class`。`init` で generation / 理由 / 全フレームのラベル・kind・ソース・区間・temp 名を読み切る。フレーム選択でソースを入れ替え区間を選択し `showFindIndicator`。variables は選択時に `receiver_print` / `temp_print` を遅延で呼ぶ。ダブルクリックで `ao_debug_inspect` → Inspector。generation が違えば print / inspect をしない。タイトル `Debugger: <理由>`。VoiceOver ラベル）。Workspace の Debug ボタン（同じ generation の窓は前面に戻す）。Browser のエラー帯は変えない

## 手順

この PR を実装するセッションは `graphify-out/GRAPH_REPORT.md` を読み、`graphify query "WorkspaceWindow InspectorWindow installErrorField"` で経路を取り、Serena で `WorkspaceWindow.run`、`installErrorField`、`failureText`、`openInspector`、`aoWorkspaceInspectHook`、`makeToolTextWindow`、`ToolTextSize`、`utf16Range`、`AoApp.resizeText`、`LaunchSet.make` の定義と参照を取ってからテストを赤にする。新規ファイル作成後は overview を取る。

`@MainActor` を GUI に付ける。強制アンラップを新規に増やさない。ウィンドウを作るテストは `tearDown` で見えている窓を閉じ、フックを外してから shutdown する。

P1 以降のコードをこの PR 文書の範囲外で書かない。Browser 連携（Browse ボタン）は足さない。
