# P11-05: Step into / over / out と Debug it

- 親フェーズ: [P11](../phases/P11.md)
- 状態: planned
- 依存: P11-04（コンパイラの文の先頭表だけは P11-01 のあと並行してよい）

## 目的

step（SPEC §3.13「操作」）と Debug it。コンパイラは文の先頭表（§3.8）を出す。インタプリタのループの先頭に 1 分岐だけ足す。

## Files

- Modify: `compiler/include/ao/MethodImage.hpp`、`compiler/src/Codegen.cpp`（`statementPcs`。バイトコードと `pcMap` は変えない）
- Modify: `runtime/src/Session.hpp`、`runtime/src/Session.cpp`（`MethodDebugInfo::statementPcs`、文の先頭のフック、`AO_EVAL_DEBUGIT`）
- Modify: `runtime/include/ao/NativeMethod.hpp`（`CallContext` の step の欄とフック）、`runtime/src/InterpFrame.hpp`（`Frame::depth`）
- Modify: `runtime/src/Interpreter.cpp`（`FrameLink` の深さ、ループの先頭の 1 分岐）
- Modify: `runtime/src/Scheduler.cpp`（step の印を立てて続ける、step で止める）
- Modify: `runtime/src/abi.cpp`、`bridge/ao_abi.h`（`ao_debug_step_into` / `over` / `out`）
- Modify: `compiler/tests/pc_map_test.cpp`、`runtime/tests/debug_abi_test.cpp`、`docs/bench.md`

## Interfaces

- Consumes: P11-04 の `resumeHalted`、P10 の pc→ソース表
- Produces: `MethodImage::statementPcs`。`CallContext::stepMode` / `stepDepth`。`ao_debug_step_*`。`AO_EVAL_DEBUGIT`

## テスト

- `pc_map_test`: `StatementPcsListEveryStatementStart`。`Codegen.*` はバイト一致
- `debug_abi_test`: `StepOverMovesToNextStatement`、`StepOverDoesNotEnterBlocks`、`StepIntoEntersInterpretedMethod`、`StepIntoSkipsNative`、`StepOutStopsInSender`、`StepPastEndFinishesEval`、`DebugItStopsAtFirstBytecode`、`DebugItOutsideLiveModeIsRefused`
- `KernelScan` 緑。`KernelBench.*` を P11-04 の HEAD と交互に 5 回ずつ測り、中央値の比が悪化しないことを `docs/bench.md` に記録する

## 手順

`graphify query "Codegen Emitter MethodImage PcSpan"` と `graphify explain CallContext` で経路を取り、Serena で `Emitter::mark`、`compileStmt`、`compileReturn`、`attachBlocks`、`Interpreter::run`、`FrameLink` の定義と参照を取ってからテストを赤にする。
