# P1-06: weak slot GC

- 親フェーズ: [P1](../phases/P1.md)
- 状態: done
- 依存: P1-05

## 目的

`kFlagWeak` のペイロードスロットは参照先を生かさない。回収後、死んだ参照は `nil`。

## Files

- Modify: `runtime/include/ao/Gc.hpp`, `runtime/src/Gc.cpp`, `runtime/tests/gc_test.cpp`

## Interfaces

- Consumes: `kFlagWeak`, nursery copy, old mark
- Produces: `Gc::clearWeakAfterNursery()`, `Gc::clearWeakAfterOldMark()`

## テスト

`GcWeak.*`（未ルートは nil、ルートは更新、old→nursery 弱参照、old mark）

## 手順

Graphify で `Gc`→`Heap` を確認し、Serena で `scavengeFromRoots` / `collectOld` の参照を取ってからテストを赤にする。ephemeron・ファイナライザキューは書かない。

## コミット文

```
Clear dead weak slots after GC

Graphify: path Gc Heap
Serena: replace_symbol_body ao::Gc::scavengeFromRoots
```
