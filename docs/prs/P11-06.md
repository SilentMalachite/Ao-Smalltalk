# P11-06: Debugger 窓の操作、Debug it、保存の拒否の警告

- 親フェーズ: [P11](../phases/P11.md)
- 状態: done
- 依存: P11-05

## 目的

Ao.app でライブデバッガを使えるようにする（SPEC §3.9 の Workspace、「ライブ Debugger」、メニュー）。

## Files

- Modify: `app/Ao/DebuggerWindow.swift`（pid、ボタン列、読み直し、閉じたら Abort、結果の受け渡し）
- Modify: `app/Ao/WorkspaceWindow.swift`（`AO_ERR_HALT` で窓を開く、`halted:` の帯、Debug it、Proceed の結果の挿入）
- Modify: `app/Ao/MainMenu.swift`（`Debug it`、`⌘⇧D`）、`app/Ao/AoApp.swift`（保存の拒否の警告）、`app/Ao/LaunchSet.swift`（`ao_set_debug_mode(AO_DEBUG_LIVE)`）
- Modify: `app/AoTests/DebuggerWindowTests.swift`、`app/AoTests/ToolWindowTests.swift`、`app/AoTests/AcceptTests.swift`

## Interfaces

- Consumes: P11-02 … P11-05 の ABI
- Produces: ライブ Debugger 窓。事後 Debugger は変えない

## テスト

`DebuggerWindowTests`: `testHaltOpensLiveDebuggerWithTemps`、`testProceedInsertsPrintItResult`、`testAbortRunsEnsureAndClosesWindow`、`testStepButtonsMoveSelection`、`testNonProceedableDisablesProceedAndStep`、`testClosingWindowAbortsProcess`、`testDoItWhileDebuggerOpen`、`testDebugItStopsAtFirstStatement`。`ToolWindowTests.testMainMenuListsToolsAndSmalltalkKeys` に `⌘⇧D`。`AcceptTests.testSaveWithHaltedProcessShowsReason`。

## 手順

`graphify query "WorkspaceWindow DebuggerWindow installDebugButton"` で経路を取り、Serena で `DebuggerWindow`、`WorkspaceWindow.run`、`openDebugger`、`MainMenu`、`LaunchSet`、`presentAlert` の定義と参照を取ってからテストを赤にする。Swift を大きく変えたら言語サーバを再起動する。
